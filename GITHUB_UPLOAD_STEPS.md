# GitHub upload steps

These steps use GitHub's web interface, so no command line is required.

1. Sign in to GitHub.
2. In the upper-right corner, select the **+** menu and choose **New repository**.
3. Use `nyc-311-dep-demand-analysis` as the repository name.
4. Add this description: `Forecasting daily NYC 311 DEP phone-request demand with regression and k-means clustering.`
5. Choose **Private** while you review the repository.
6. Do not add a separate README, `.gitignore`, or license during setup because those files are already included in this package.
7. Create the repository.
8. On the repository page, choose **Add file**, then **Upload files**.
9. Drag in the contents of this folder. Preserve the `code`, `data`, `docs`, `results`, and `visuals` folders.
10. Add the commit message `Add NYC 311 demand-analysis portfolio project` and commit the files.
11. Review the README and open each chart, report, and presentation.
12. When everything looks correct, open **Settings**, locate repository visibility, and change the repository to **Public**.
13. Copy the public repository link and send it to Dr. Wolfe.

Before making the repository public, confirm that it contains no passwords, tokens, private company information, personal contact details, or unfinished drafts.
